# Змейка на Python

Простая классическая «Змейка». Реализована на стандартной библиотеке
(`tkinter`) — дополнительные зависимости устанавливать не нужно.

## Запуск

```bash
python snake.py
```

## Управление

| Клавиши              | Действие                     |
|----------------------|------------------------------|
| Стрелки / WASD / ЦФЫВ | направление движения        |
| Пробел               | пауза / продолжить          |
| R                    | начать игру заново          |
| Esc                  | выход                        |

## Правила

* Змейка растёт на 1 клетку за каждую съеденную еду (+10 очков).
* Скорость растёт с каждой съеденной едой: от 140 мс до 55 мс между шагами.
* Разворот на 180° запрещён (иначе змейка врезалась бы сама в себя).
* Столкновение со стеной или с собственным телом завершает игру.
* Если заполнить всё поле — победа.

## Структура

```
snake/
├── snake.py       # игра: логика (SnakeGame) + отрисовка (SnakeApp)
├── test_snake.py  # юнит-тесты игровой логики (17 шт.)
└── smoke_test.py  # дымовой тест графики
```

Логика (`SnakeGame`) полностью отделена от tkinter, поэтому её легко тестировать.

## Тесты

```bash
python -m unittest test_snake -v   # юнит-тесты логики
python smoke_test.py                # проверка окна и отрисовки
```
